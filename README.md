# 🎓 AI Prerequisite Finder for Learning

AI Prerequisite Finder is an AI-powered learning assistant that helps students identify the concepts they should learn before starting a new Data Science or Artificial Intelligence topic.

## 🚀 Technologies Used

- Python 3.11
- Streamlit
- LangChain
- Ollama
- Llama 3.2
- ChromaDB
- Sentence Transformers
- Whisper
